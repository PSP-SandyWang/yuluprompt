AI 提示詞工具包
================================================

【怎麼用】
1. 提示詞組裝台.html   ← 主工具。直接用瀏覽器開啟（雙擊即可）
2. 分鏡台.html         ← 影片多鏡頭規劃，一鏡產一段提示詞
3. 圖影提示詞手冊.html ← 教學手冊（含 39 組失敗診斷表，可搜尋）

兩個都是「單一檔案」，不需要安裝任何東西。
可以複製到隨身碟、雲端硬碟、或任何電腦使用。
※ 需要連網才會載入字型（斷網仍可用，只是字體會變）

【線上版（隨時可開，手機也能看）】
組裝台：https://claude.ai/code/artifact/104eb388-9f65-4c1f-a4d5-ab6485ab908b
分鏡台：https://claude.ai/code/artifact/7842ca0f-dffe-4748-9178-11aecd8c690d
手　冊：https://claude.ai/code/artifact/86c1453d-428a-4cbf-9c91-32c74cd1be39

【詞庫資料】
提示詞詞庫_全部.csv  ← 2061 組中英對照，一個檔全部。可直接用 Excel 開
提示詞詞庫.json      ← 給之後做網站 / 資料庫用的格式
CSV_分頁/            ← 24 個檔，每個欄位一個，可逐一拖進 Excel 當新分頁
bankdata.js / bank2.js ← 組裝台內嵌的原始資料（備份用）

【想架成網站給朋友用】
「提示詞組裝台.html」是完整的靜態網頁，可直接上傳到：
  GitHub Pages / Netlify / Vercel / 任何虛擬主機
改檔名為 index.html 上傳即可，不需要後端。

【自訂詞會存在哪】
你在組裝台按「＋」加的自訂詞，存在「該台電腦的瀏覽器」裡。
換電腦或清除瀏覽器資料就會消失。
要跨裝置共用，需要改成雲端資料庫版本。
