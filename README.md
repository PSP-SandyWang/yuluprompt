# AI 提示詞工作台

給設計師用的一整套 AI 生圖／生影提示詞工具。**六個單一 HTML 檔，不需要後端、不需要安裝、不需要 API key**，用瀏覽器直接開就能用。

全站共 **3,856 組中英對照詞彙**，三個組裝台共用同一份。欄位填中文，輸出時自動換成模型看得懂的英文。

👉 **[線上使用](https://USERNAME.github.io/REPO/)**（把 `USERNAME` 和 `REPO` 換成你的）

## 內容

### 三個組裝台 — 同一份詞庫，三種填法

| 檔案 | 工具 | 適合誰 |
|---|---|---|
| `wizard.html` | **提示詞引導台** | 新手、想邊做邊學 |
| `nest.html` | **提示詞組裝台 · 巢狀版** | 要組一張完整的 |
| `builder.html` | **提示詞組裝台 · 原版** | 已經知道自己要填什麼 |

**引導台** 一步一題，每步說明為什麼要填。第一步選類型（人物／商品／風景／非人類／影片首幀），後面整份跟著變 —— 選人物就問「畫面裡有誰」並逐一設定每個角色，選商品就直接問「主角是什麼物件」，選風景則改問背景人群。多角色是 1＋1＋1 的分頁設定，避免模型把兩個人的特徵混在一起。六步走完（影片首幀七步）。

**巢狀版** 八個章節收合，打開只看到八行，要哪章點哪章。最上面有起手式：8 組用途一鍵填多欄、8 組負面起手包。

**原版** 49 個欄位全部平鋪，適合已經熟了之後快速微調。輸出可切換 Krea 2、GPT Image 2、MiniMax H3、標籤式 SD、標籤分區版、人物設定表六種語法。

### 專用工具

| 檔案 | 工具 | 做什麼 |
|---|---|---|
| `ad.html` | **廣告視覺台** | 產品視覺與 banner，31 個欄位含版位檔期、相機規格、去背輸出、鎖定不可更動細節 |
| `storyboard.html` | **分鏡台** | 多鏡頭敘事，每顆鏡頭各自產出影片提示詞，共用設定自動帶入維持角色一致 |
| `handbook.html` | **圖影提示詞手冊** | 六章教學、四張模板卡、39 組失敗診斷表（症狀 → 原因 → 怎麼改） |

`wordbank.json` — 完整詞庫原始資料（3,890 組中英對照），想自己接程式可以用這份。

## 怎麼用

**直接下載**：抓整包，用瀏覽器開 `index.html`。離線可用。

**開 GitHub Pages**：
1. Settings → Pages → Source 選 **Deploy from a branch**
2. Branch 選 `main`、資料夾選 `/ (root)`，Save
3. 等一兩分鐘，網址會是 `https://你的帳號.github.io/repo名稱/`

倉庫裡已經放了 `.nojekyll`，GitHub Pages 不會去跑 Jekyll 處理。

## 幾個設計上的決定

**欄位填中文、輸出英文。** 詞庫的結構是「中文標籤 → 英文內容」，所以你在欄位裡看到的是「電影感光線」，複製出去的是 `cinematic lighting, soft key light from the left`。負面詞、畫質詞、Pony 分數這類純模型 token，不管選哪個語言都輸出英文。

**不使用在世創作者或現行工作室名稱。** 所有風格詞都以視覺特徵描述（例如用「高對比硬光、冷藍調、淺景深」而不是某位攝影師的名字）。已故且作品進入公有領域的畫家例外。

**多人一定要逐一寫。** 把「二十多歲女性穿紅洋裝」和「三十多歲男性穿西裝」分開描述，模型才不會把特徵混在一起。標籤式輸出會用 `BREAK` 分隔角色。

**隨機是等機率抽樣。** 不是先抽分類再抽詞 —— 那樣小分類的詞會被放大好幾倍，看起來像一直跳出同幾個字。整句組合包、寫法教學句、會改寫整個構圖的第一人稱視角都排除在隨機之外，但手動還是選得到。

## 技術

- 純靜態 HTML／CSS／JS，每個工具都是單一檔案
- 沒有建置流程、沒有相依套件、沒有追蹤碼
- 填過的內容存在瀏覽器的 localStorage，換裝置不會跟著走
- 外部只連 Google Fonts（Noto Sans TC、JetBrains Mono）
- 深色模式跟著系統走
